# Cinematic Assets

- `clock-face.webp`, `clock-hour.webp`, `clock-minute.webp`, `clock-hub.webp`: raster dial and hand cutouts used by `MidnightClock.tsx`.
- `lantern-wraith.svg`: the lantern wraith vector illustration with animated glow used by `MidnightIntro.tsx` and `LanternWraith.tsx`.
- `crew-eye.svg` and `umbrella-ghost.svg`: the eye awakening and floating umbrella character used by `CrewAwakening.tsx`.
- `barlow-condensed-800-italic.ttf`: display face used for Violet Midnight headings (`OFL.txt`).
