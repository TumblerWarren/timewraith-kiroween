# Per-part wording

> Template. Task 11.1 fills this file in from `tools/art/assets.spec.json`. Until then, read the entry for the asset id in `assets.spec.json` directly.

One section per mascot, one line per part or pose. Keep each line to a single subject sentence that can be dropped into the **subject block** of `prompt-template.md`.

## Entry format
```
### <mascot id> (<display name>)
- <part or pose id>: <subject sentence>. Framing: <framing>. Fallback: <pose id or "none">.
```

## Example (placeholder, not final wording)
```
### mini-bat (Mini Bat)
- body: <single cartoon bat body without wings, front view>. Framing: centered, wide margin. Fallback: none.
- wings: <pair of open bat wings, no body>. Framing: centered, wide margin. Fallback: pose.
```
